# Barbería y Peluquería Jhon — Web V4

## Vista previa
https://matiaszzz-ai.github.io/barberia-jhon-web/

## Estructura publicada
- `index.html`, `servicios.html`, `barberos.html`, `productos.html`, `videos.html`, `reservas.html` y `ubicacion.html`
- `assets/styles.css`: diseño visual
- `assets/data.js`: servicios, precios y equipo
- `assets/site.js`: interacciones y reproductor
- `assets/*.webp`, `assets/logo-jhon.png`: fotografías e imágenes
- `videos/*.mp4`, `videos/*.jpg`: cinco videos y miniaturas

Las rutas de los videos se han ajustado para leerlos desde la carpeta `videos` de la raíz, tal como quedaron subidos a GitHub. No hace falta cargarlos de nuevo ni moverlos.

## Publicación
GitHub Pages está configurado para publicar `main` / `(root)`. Al actualizar el código de la rama `main`, se vuelve a publicar el mismo enlace tras completar el despliegue.

**Importante:** Las reservas y calificaciones continúan siendo demostrativas hasta conectar servicios reales. La tienda no recibe pagos directamente.
